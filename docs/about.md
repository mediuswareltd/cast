# About Cast

## Who maintains it

Cast is built and maintained by [Mediusware](https://mediusware.com), a software company that designs and ships products for clients worldwide. The source lives at [github.com/mediuswareltd/cast](https://github.com/mediuswareltd/cast).

## Why it exists

A lightweight Rust service for fast video/audio format conversion with automatic file cleanup and no persistent storage.

We publish these tools so teams can evaluate the real software, not a slide deck: clone it, run it, and read how it is put together.

## Documentation

- Docs site: https://mediuswareltd.github.io/cast/
- Getting started, guide, and about pages are generated from the project README and kept next to the code under `docs/`.
