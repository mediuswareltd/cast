# Getting started

Install and run **Cast** locally.

## Prerequisites

- Working knowledge of Rust
- Git and a terminal

## Install

```bash
cargo build --release
# requires FFmpeg on PATH
```

## Quick start

```bash
# start the API (see README for exact binary/flags)
./target/release/cast
```
