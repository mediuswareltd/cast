# Guide

## What it is

A lightweight Rust service for fast video/audio format conversion with automatic file cleanup and no persistent storage.

## Stack

`Rust`, `FFmpeg`, `REST`

## Capabilities

### Multiple formats

MOV↔MP4, WEBM→MP4, MP4→MP3 and more via FFmpeg.

### Privacy first

Temporary files only; deleted after download or timeout.

### Size limits

200MB video / 100MB audio caps with clear API errors.

### REST + CORS

Simple HTTP endpoints ready for local or internal use.
